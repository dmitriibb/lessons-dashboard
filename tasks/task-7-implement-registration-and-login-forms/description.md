# Main Goal
Implement frontend registration and login forms and route the user to a Hello World page after login.

# Details
Update the React app so that:
- when the home page is opened by a user who is not logged in, the user can choose to register or log in
- when the user is logged in, the app shows a Hello World page

Implement frontend forms for registration and login.
Integrate them with the backend authentication APIs.
Use the backend authentication approach defined by the backend tasks.

The initial logged-in experience can stay simple.
The main goal is to complete the first end-to-end auth flow from UI to backend.

# Definition of Done
An unauthenticated user opening the app can register or log in from the home page.
After successful login, the user sees the Hello World page.
The frontend is integrated with the backend registration and login APIs.

# Restrictions
Keep the initial UI simple.
Do not add unrelated product features in this task.
The task should focus on completing the first working authentication flow in the frontend.
