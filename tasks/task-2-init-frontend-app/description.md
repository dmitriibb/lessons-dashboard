# Main Goal
Create an initial React frontend application in this repository under the `/client_react` folder.

# Details
Set up a normal React application inside `/client_react`.
This app does not need server-side rendering.
The goal of this task is to initialize the frontend project structure so it can be developed locally and later integrated with the backend and Docker-based deployment.
The app should be ready to run locally in development mode.

# Definition of Done
There is a working React application under `/client_react`.
The frontend can be installed and started locally.
The repository structure clearly separates the frontend app from the Go backend.

# Restrictions
Do not put the frontend app in the project root.
The frontend must live under `/client_react`.
Keep the initial setup simple and suitable for future integration with backend APIs and Docker Compose.
